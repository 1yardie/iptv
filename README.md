# iptv

- **DistroTV playlist:** `streams/distro_new.m3u` (includes EPG URL in the header).
- **TV guide not working?** See [EPG_TROUBLESHOOTING.md](EPG_TROUBLESHOOTING.md).

`main.m3u` is generated by `sync_buddylive_to_tv_channels.py`. The scheduled
workflow runs every three hours. Reviewed removals and replacement URLs are in
`playlist_updates.json`; rules match the source section, complete channel name,
and guide ID so similarly named regional feeds and future events stay separate.
Remove or revise an exclusion rule if a channel is intentionally restored.

LocalNow replacements are refreshed from the public player during each sync.
The resolver validates the channel identity and strips caller IP/device data
while preserving required channel-routing parameters. If renewal fails, the
sync logs the channel name and uses its last reviewed fallback URL. These checks
do not guarantee long-term availability or playback on every device. TiviMate
must reload the playlist to receive changed URLs. Pluto renewal is not added by
these rules.
